# Mortgage product requirements

A starter workspace for a product manager and an AI requirements partner. No application code or AI service is included. All examples are fictional and unapproved.

## Start here
1. Extract this folder. Create a private repository named `mortgage-product-requirements` in your approved GitHub or GitLab organisation.
2. Open this folder in your agent-enabled editor. Read `AGENTS.md` and `SETUP.md`.
3. Complete `project-context.md`. Unknown information can remain `Unknown`.
4. Copy `templates/capability/` to `capabilities/<short-capability-name>/`.
5. Use the first-session message in `prompts/session-prompts.md`.
6. Review the changed files, commit them and push them to your repository.

The product manager owns business decisions. The agent investigates, recommends, asks questions and records decisions. Chat history is supplementary; the saved files preserve agreed state.

## Files
- `AGENTS.md`: permanent agent workflow and decision boundaries.
- `CLAUDE.md`: directs Claude Code to the same instructions.
- `project-context.md`: application scope and access references.
- `standards/`: writing profile, glossary and review checklist.
- `templates/capability/`: three reusable capability records.
- `capabilities/README.md`: index of active work.
- `examples/`: fictional demonstration, never an approved specification.
- `prompts/`: messages for starting, resuming and closing sessions.
